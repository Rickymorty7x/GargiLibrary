# Contributing to GargiLibrary

Thank you for helping make open PDF discovery better. Bug reports, documentation, design improvements, new lawful search providers, accessibility fixes, and code contributions are welcome.

## Before you begin

- Search existing issues before opening a new one.
- Keep changes focused and explain the user benefit.
- Only integrate sources whose APIs, terms, licenses, and access controls permit the proposed use.
- Never add scraped credentials, secrets, copyrighted files, paywall bypasses, or access-control circumvention.
- Test direct PDF links responsibly and respect publishers' robots, quotas, copyright, and licenses.

## Development

```bash
npm install
npm run dev
npm run build
```

## Pull requests

1. Fork the repository and create a focused branch.
2. Make the change and run `npm run build`.
3. Describe what changed, why, and how you tested it.
4. Include screenshots for visible interface changes.
5. Disclose meaningful AI assistance and verify all generated code, claims, licenses, and tests yourself.

By submitting a contribution, you agree that it is licensed under the repository's MIT License and that you have the right to submit it.

## AI contributions

This project itself was developed entirely with AI using OpenAI Codex under human direction. AI-assisted contributions are welcome, but the submitting human remains accountable for correctness, security, attribution, and licensing.
